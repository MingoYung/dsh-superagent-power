# 验证记录

## 2026-11-02：首版

公开源码通过独立依赖安装、构建和 9 项自动化测试，无需开发者全局 DSH 包路径。CI 在 Windows / Node.js 24 上重复运行这些检查。

| 检查 | 结果 / 范围 |
| --- | --- |
| 浏览器模块加载 | 仅使用 React / React DOM 宿主种子；remote-info 被打包 |
| 启停与重复操作 | 使用真实子进程夹具；确认退出前收尾标记已写入，重复开启不创建第二个 worker |
| 忙碌保护和版本冲突 | 无中断确认的关闭和过期 revision 被拒绝 |
| 认证拒绝 | 错误密钥不能停止 worker |
| 桌面生命周期和记忆 | 关闭控制者后 worker 退出，重新初始化沿用开启选择 |
| 重复控制者 | 第二个控制者不能抢占，也不能在清理时关闭现有 worker |
| 端口冲突 | 拒绝启动且不终止端口占用者 |
| IPC 断开 | 托管连接断开后 worker 尝试正常收尾并退出 |
| 原生 Gateway | 类型校验、owner 调用和未授权 peer 拒绝通过 |

本机额外验收（CI 不包含真实桌面和业务环境）：

- DSH NEXT `2.0.21-next` / 内嵌 DSH `0.2.1-rc.4`；独立 CLI `0.2.1-rc.5`；Super-agent `0.1.0` 的现有本机安装。
- 在新会话与已有会话中观察到同一个全局状态，按钮名称为 `Sup`。
- 真实 CLI + Super-agent 的隔离 profile 启动、关闭成功；一次观测启动约 7.3 秒、关闭约 0.2 秒，仅供参考。
- 实际桌面按钮启停通过。测试暂用无业务凭据的隔离状态目录；测试后恢复原 profile 并验证文件哈希。
- 最终检查后台进程已退出、相关端口未监听、选择持久化为关闭。
- 关闭前一个后台主进程 RSS 约 468 MB；退出后该进程不再存在。不是普遍性能基准。

本机 Super-agent 安装包含已有环境适配，不能把上述结果当作所有上游发行版的兼容承诺。未验证所有业务事件源、外部任务执行恢复、其他操作系统或未来 DSH 接口变化。
